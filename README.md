# CultureMate — Render-ready prototype

## Upload
Extract this ZIP. Open the extracted folder and upload its FILES to the top level of the CULTUREMATE-AI GitHub repository. Upload index.html, home.html, style.css, app.js, render.yaml and README.md together. Do not upload the ZIP or an enclosing folder.

## Render settings
Service type: Static Site
Branch: main
Root Directory: leave empty
Build Command: echo "CultureMate ready"
Publish Directory: .
No start command. No environment variables. Deploy latest commit.

The original app is now index.html so the main website URL opens it directly. Its HTML, styling and app JavaScript are unchanged. home.html is also retained for old links. This package omits the nonfunctional platform-only ChatGPT sign-in entry page. Google/email authentication, Qloo and live generative AI are not implemented. Recommendations use a curated catalogue and rule-based matching. Preferences and favourites use browser storage.

Double-click index.html to try locally.
